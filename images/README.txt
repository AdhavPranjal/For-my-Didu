HOW TO ADD PRISHU'S PHOTOS:
-----------------------------
Drop your photos into this folder and name them exactly as below.

GALLERY PHOTOS (shown in the Photo Gallery section):
  photo_1.jpg   ← Slot 1  (Category: Cute)
  photo_2.jpg   ← Slot 2  (Category: Cute)
  photo_3.jpg   ← Slot 3  (Category: Funny)
  photo_4.jpg   ← Slot 4  (Category: Travel)
  photo_5.jpg   ← Slot 5  (Category: Besties)
  photo_6.jpg   ← Slot 6  (Category: Cute)

  Note: The existing file "didu_photo_1.png" is already set
        as photo_1 in the gallery.

MEMORY TIMELINE IMAGES (shown in the Memories section):
  memory_1.jpg  ← Memory 1: Growing Up Together
  memory_2.jpg  ← Memory 2: First Major Adventure
  memory_3.jpg  ← Memory 3: Midnight Conversations
  memory_4.jpg  ← Memory 4: Today & Forever

TIPS:
  - Any common format works: .jpg, .jpeg, .png, .webp
  - Keep file sizes reasonable (under 2MB each) for fast loading
  - Landscape/square photos look best in the gallery (4:3 ratio ideal)
  - If a photo is missing, a pretty pink placeholder will show instead

CUSTOMIZING CAPTIONS & TITLES:
  Open js/sisterData.js and find the "photos" and "memories" arrays.
  You can change the title, caption, category, and filename there.
